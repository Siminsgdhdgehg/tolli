# Tolli

*Tolli is a web-based incident reporting and discovery system. Users can report incidents and search for incidents within a specified distance.*

**Features:**

  Report incidents

  Search for nearby incidents

  Calculate distance using latitude and longitude

  Set incident severity

  Display verified and unverified incidents

  Store incident data.

Technologies:

  HTML
  CSS
  JavaScript
  Node.js
  Express
  JSON
The search uses latitude, longitude, and radius parameters.

<small>this is a fun project i made not intended to replace actual reporting systems</small>
